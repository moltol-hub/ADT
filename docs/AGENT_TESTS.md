## 30.08.2026 — Алиса: массаж, Смирновская улица, Москва

### Наблюдение
Пользователь задал Алисе high-intent local запрос: «Посмотри массаж в районе улица Смирновская в Москве». Текущая физическая геолокация пользователя при этом находилась не в Москве.

Алиса сформировала shortlist из двух организаций:
- «Серебро» — Москва, Смирновская ул., 4Б: корректное соответствие explicit geo.
- «Эстеттика» — Московская область, Люберцы, Смирновская ул., 7/170: другое муниципальное образование и другая одноимённая улица, несмотря на явное ограничение «в Москве».

В ответе и карточках наблюдались внешние источники данных, включая Flamp и сайт бизнеса на `clients.site` (YCLIENTS), а также обогащение/действия через Яндекс Карты. В интерфейсе доступны коммерческие CTA: телефон/звонок и онлайн-запись.

### Интерпретация
1. Алиса реально обслуживает local high-intent demand и формирует shortlist конкретных исполнителей, а не только список ссылок.
2. В agent retrieval участвуют внешние источники помимо карточки Яндекс Карт; следовательно, существует потенциально доступный data/distribution layer.
3. Explicit Geo не обязательно работает как hard filter: запрос «Москва» допустил организацию из Люберец из-за совпадения названия улицы.
4. Device geo не является обязательным ограничением: пользователь находился не в Москве, но Алиса обработала явно заданный московский geo.
5. Ошибка показывает потенциальный data/routing gap: нормализация `intent → explicit geo → entity → provider` пока несовершенна.

### Evidence для H2a Agent Distribution
Кейс является первым прямым наблюдением цепочки:

`high-intent local query → AI shortlist → конкретные local businesses → внешние data sources → коммерческий CTA`

Это подтверждает существование agent distribution как реального канала local demand, но НЕ подтверждает возможность бизнеса или контроля канала.

### Следующая проверяемая гипотеза
Можно ли создать/контролировать источник структурированных данных о локальных исполнителях, который AI систематически использует при retrieval/ranking и через который можно получать high-intent leads?

### Метрики
- **Geo Precision** — доля рекомендаций, соответствующих explicit Geo. В данном единичном кейсе: 1/2.
- **Source Share** — доля рекомендаций/атрибутов, поддержанных каждым типом внешнего источника.
- **CTA Coverage** — доля результатов с коммерческим действием (звонок/запись).
- **Repeatability** — стабильность shortlist и источников при повторении эквивалентного запроса.

### Статус вывода
**H2a: evidence канала усилен. Controllability не доказана.** Следующий приоритет — не массовый supply parsing, а воспроизводимый Search vs AI тест и проверка того, можно ли влиять на agent retrieval/ranking через контролируемый источник данных.
