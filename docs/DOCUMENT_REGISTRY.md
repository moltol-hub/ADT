# ADT Document Registry

This registry keeps ADT aligned with Project Framework.

| Document | Framework Role | Status | Update When |
| --- | --- | --- | --- |
| `README.md` | Project overview | Active | Current status, baseline, or repository shape changes. |
| `docs/WIKI_INDEX.md` | Wiki Index | Active | New core documents are added or roles change. |
| `docs/AGENT_CONTEXT.md` | Agent Context | Active | Stable project state, rules, or active tasks change. |
| `docs/DOCUMENT_REGISTRY.md` | Document registry | Active | A document is added, removed, renamed, or changes role. |
| `docs/DEVELOPMENT_PROCESS.md` | Development/process | Active | Change flow, access notes, or iteration process changes. |
| `docs/CHANGE_SPECIFICATIONS.md` | Specifications | Active | A significant change is planned or completed. |
| `docs/DECISIONS.md` | Decision log | Active | A project-level decision is made or reversed. |
| `docs/HYPOTHESES.md` | Hypothesis register | Active | A hypothesis becomes active, parked, proven, or rejected. |
| `docs/IDEAS.md` | Parked ideas | Active | A useful observation is not yet an implementation task. |
| `docs/EXPERIMENTS.md` | Experiment index | Active | A test is planned, run, or summarized. |
| `docs/AGENT_TESTS.md` | Detailed experiment log | Active | A real agent-style behavior test is run. |
| `docs/RELEASES.md` | Releases | Active | A baseline version is created, deployed, or retired. |
| `docs/ROADMAP.md` | Roadmap | Active | Next steps or priorities change. |
| `docs/ARCHITECTURE.md` | Architecture | Active | Human/agent interface, API, data, or runtime structure changes. |
